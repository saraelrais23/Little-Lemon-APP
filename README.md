# Little Lemon

A responsive restaurant website built with HTML, CSS, and vanilla JavaScript.

## Features

- Browse the menu and open dish details.
- Add dishes to the cart, change quantities, remove items, and see the subtotal.
- Complete a demo checkout for pickup or dine-in. No payment is collected.
- Request a table reservation with a date, time, guest count, name, and email.
- Create a local demo account, sign in, and sign out.
- Switch between light and dark themes; the selected theme is remembered in this browser.
- Cart, demo orders, and reservation requests are stored in this browser's `localStorage`.
- Responsive navigation and layouts for mobile, tablet, and desktop.

## Run locally

Open `index.html` in a browser or serve this directory with a local static web server.

## Limitations

This is a front-end demo; it has no backend, real payment processing, or booking availability checks. Demo accounts, requests, and orders are kept only in this browser and are not sent to the restaurant. The local sign-in is not production authentication; do not use real or reused passwords.
